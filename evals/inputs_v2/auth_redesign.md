# 鉴权重构方案 (draft)

我们要把现在的 session-cookie 鉴权换成无状态 JWT。目标是后端水平扩展时不用共享 session 存储。

## 方案

1. 用户登录成功后，后端签发一个 JWT（HS256，密钥写在环境变量里），有效期 7 天，放在 `Authorization: Bearer` 头里。
2. 每个请求，后端用密钥验签 JWT，验过就放行，从 payload 里直接取 `user_id` 和 `role`。
3. 前端把 JWT 存在 localStorage，过期了就跳登录页重新登录。
4. 用户改密码 / 被封号时，后端在 DB 里把用户标记为 invalid。

## 我们关心的点

- 后端完全无状态，任意一台机器都能验 token。
- 登录后 7 天内不用反复登录。

这个方案我觉得挺简洁的，但总觉得有些地方没考虑周全。
