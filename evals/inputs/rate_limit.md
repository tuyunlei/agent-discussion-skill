# API 限流方案 (draft)

开放平台 API 要按 API key 限流，规则是「每个 key 每分钟最多 600 次」。后端是多实例部署。

## 方案

1. 用 Redis 计数：key 用 `ratelimit:{api_key}:{当前分钟}`，每次请求 `INCR`，第一次 `INCR` 后给这个 key 设 60 秒过期。
2. `INCR` 之后的返回值如果 > 600，就拒绝，返回 429。
3. 每分钟天然换一个新 key（因为 key 里带了分钟），所以不用手动清零。

## 我们关心的点

- 多实例共享同一份计数，限流要准。
- 实现尽量简单。
